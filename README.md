# ZAYSSME

Minimal monochrome developer portfolio built with Astro.

A fast, lightweight, and modern portfolio focused on performance, clean aesthetics, and scalable frontend architecture.

---

## Tech Stack

- Astro
- TypeScript
- Tailwind CSS
- React (optional islands)
- Framer Motion
- Lucide Icons

---

## Philosophy

This project is built around a simple idea:

> Minimal UI. Maximum clarity.

The design focuses on:
- monochrome aesthetics
- high readability
- smooth interactions
- lightweight performance
- clean developer experience

Inspired by modern product-focused interfaces such as:
- Linear
- Vercel
- Raycast

---

## Features

- Minimal black & white design
- Fully responsive layout
- High Lighthouse performance
- SEO optimized
- Reusable component architecture
- Smooth and subtle animations
- Static-first rendering with Astro
- Lightweight client-side JavaScript

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
